# Twitter X Clone

A modern and responsive **Twitter/X inspired social media interface** built with React and Vite. This project recreates the core layout, interactions, and visual experience of a social media platform with a clean and responsive frontend.

## 🚀 Live Demo

**[View Live Demo](https://twitter-x-clone-sigma.vercel.app/)**

## 📌 About The Project

Twitter X Clone is a frontend project created to practice modern web development using **React, Vite, Tailwind CSS, and reusable UI components**.

The application focuses on building a responsive social media interface inspired by X, including navigation, home feed, user profiles, notifications, messages, search, trends, and interactive UI elements.

## ✨ Features

- 🏠 Home feed with posts and interactions
- 🔍 Explore and search interface
- 🔔 Notifications section
- 💬 Messages interface
- 👤 User profile pages
- ❤️ Like interactions
- 🔁 Repost/share interactions
- 📌 Navigation sidebar
- 📈 Trending topics section
- 📱 Responsive design
- 🎨 Modern X-inspired UI
- 🧩 Reusable React components
- ⚡ Fast development with Vite
- ✨ Smooth UI interactions and animations
